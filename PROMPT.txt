我想要一个能在浏览器里用的 JSON Schema 可视化表单生成器：一边是可视化的表单结构编辑区，一边是原始的 Schema 文本编辑区，两边表达的是同一份 JSON Schema，任何一侧的改动都要实时反映到另一侧，并据此即时渲染出这份 Schema 对应的可填写表单预览。整套东西以浏览器交互为主体，后端负责 Schema 的解析校验、控件映射、双向变换与持久化。

双向同步是这个工具的核心，要做到可信：在文本编辑区里修改 Schema，可视化结构区与右侧表单预览要同步更新；在可视化结构区里增删字段、调整字段类型、约束与嵌套层级，文本编辑区里的 Schema 文本也要相应更新。当文本编辑区里的内容一时不是合法的 JSON 或不是合法的 Schema 时，工具不能崩坏，也不能把可视化区清空，而要保留在最近一次合法状态上继续可编辑，并明确提示当前文本非法及原因；等文本重新变回合法，两侧再次接上。请把「最近一次合法状态」的判定与回退逻辑做扎实，这是两侧不打架的关键。

Schema 到控件的映射要覆盖常见形态：字符串、数值、整数、布尔、枚举分别映射到文本框、数字输入、勾选、下拉等合适控件；对象类型渲染为分组的嵌套字段，数组类型渲染为可增删的重复项；字段上的约束（必填、最小/最大值、字符串长度、正则模式、枚举取值、默认值）要在生成的表单预览里真正生效，即在预览表单中填写并校验时，违反约束的输入被拦下并给出定位到字段的提示，符合约束的输入被接受。工具还要能把当前 Schema 导出，并能导入一份外部 Schema 反向铺开成可视化结构与文本两侧。

Schema 文档作为一等实体持久化：用户可以新建、命名、保存、载入多份 Schema 文档，服务端存住每份文档的当前内容；为便于回溯，保存时留存版本轨迹，允许查看某一历史版本并回滚到该版本。请预置一份可直接载入把玩的示范 Schema（含嵌套对象、数组、枚举与若干约束的报名表一类结构），载入后可视化区、文本区与表单预览三者应彼此一致、可交互。

要有清晰的成功判据并有自动化测试守住：同一份 Schema 经「可视化结构 → Schema 文本 → 再解析回结构」一圈往返后语义不变；文本区键入非法内容时可视化区停留在最近合法态且不被清空、恢复合法后重新同步；生成的预览表单对违反约束的输入拦截、对合法输入放行；导出再导入同一份 Schema 得到等价结构；历史版本回滚后文档内容与所选版本一致。多个 Schema 文档之间各自独立，并发编辑不同文档时内容不得互相覆盖或串号。

范围限定在 JSON Schema 的可视化编辑、双向同步、表单预览与文档持久化，不涉及账户体系与第三方登录。请用 Vue 3 搭配 TypeScript 做前端，后端语言与框架自定（选用本地常见的运行时版本），配一个持久化存储保存 Schema 文档与版本轨迹。代码按职责拆分为多个模块与文件：前端的结构编辑区、文本编辑区、表单预览各自独立的组件，后端的 HTTP 路由、Schema 解析校验、结构与文本的双向变换引擎、控件映射、文档与版本持久化各自独立成文件，避免把核心逻辑堆在单个巨型文件里。交付时应能在容器中一并构建并拉起前端、后端与存储，对外暴露页面与接口，并随附覆盖往返语义不变、非法态回退、约束校验、导入导出与版本回滚的自动化测试。
